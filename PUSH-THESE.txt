TWO PLACES, AS ALWAYS
------------------------------------------------------------------

  1. GitHub: upload faculty-intro.html, index.html and
     compliance-notes.md to the repo root. Commit. This updates the
     GitHub Pages copies.

  2. Apps Script: open the sheet, Extensions, Apps Script.
       - Paste index.html over the HTML file named Index (capital I).
       - Paste code.gs over Code.gs only if you have not already.
       - Deploy, Manage deployments, pencil icon, Version: New version.
     The URL does not change.
